# Audit your teammate's project

**Track:** Module 7 — EU AI Act · **When:** Week 7, Day 2 · **Status:** Required

**Teammate audited:** GordonS · **Project audited:** Stups (personal daily evening-suggestion agent, built on n8n)

This repository contains everything you need for this lab.

## Files

- [`instructions.md`](./instructions.md) — the lab instructions
- [`rubric.md`](./rubric.md) — how your submission is graded; this is what the AI reviewer checks your PR against
- [`stups_peer_audit_report.md`](./stups_peer_audit_report.md) — my peer audit deliverable, structured to match `instructions.md` phase by phase:
  - **Phase 1: Read and annotate** — underline / circle / mark annotations
  - **Phase 2: First-pass classification** — risk-tier table with Article/Annex justification
  - **Phase 3: Clarifying questions log** — questions, why they matter, provisional assumptions, answers received
  - **Phase 4: Audit report** — all 6 required sections: (1) system summary, (2) risk classification, (3) role map, (4) compliance findings with severity, (5) overall recommendation, (6) disclaimer
  - **Phase 5: Debrief conversation** — five-step sequence and joint closing note

## How to complete this lab

1. **Fork** this repository.
2. Do the work described in `instructions.md`, committing to your fork.
3. Open a **pull request** back into this repository.
4. You'll receive **AI feedback** on your PR based on `rubric.md`. Address any blocking feedback and push updates to the same PR.

## Submission hygiene

- Keep this repository scoped to this lab only — no unrelated projects or personal files.
- Use clear, descriptive filenames.
- Remove secrets, API keys, and tokens before committing.
